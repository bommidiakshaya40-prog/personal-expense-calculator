# Personal Expense Calculator (Console App)

A beginner-friendly command-line Python application to track and calculate daily personal expenses.

## Features
- **Add Expense**: Enter an expense description and amount with input validation.
- **View All Expenses**: Displays a clean, formatted table listing every recorded expense.
- **Calculate Total Spending**: Sums up all recorded expenses and displays the grand total.
- **Interactive Menu Loop**: A clear, looping console menu allowing repeated actions until the user chooses to exit.

## How to Run

1. Make sure Python 3 is installed on your computer.
2. Open your terminal or command prompt in this folder.
3. Run:
   ```bash
   python main.py
   ```
